# Reporting issues

Use GitHub Issues for reproducible bugs. Remove personal paths, player addresses,
passwords, tokens and save files from reports. Do not publish a private multiplayer
room password. These are experimental native/VR releases; use a separate Skyrim
mod profile and a disposable/new save when testing.

The launchers do not install drivers, change a headset runtime, open firewall ports,
or disable security software. No software signing certificate is supplied. Do not
disable security controls to run this project; if your computer blocks it, report
the exact message or build the source yourself.
